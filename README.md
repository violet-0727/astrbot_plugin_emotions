# 她自己的情绪

独立的情绪插件。不依赖、不修改任何其它插件。

## 为什么是两套状态

情绪不是一根数值条。同样「心情差」，对**生人**是冷淡敷衍，对**亲近的人**反而会黏过去——

```
              关系远          关系近
心情好        客气疏离        话多、主动
心情一般      正常应付        随意、偏亲近
心情差        冷冷淡淡        闷着，想找人陪
```

所以插件存两份：

| 层 | 维度 | 决定什么 |
|---|---|---|
| **全局** | 心情 mood / 精力 energy / 耐心 patience / 黏人 cling | 整体的说话基调 |
| **用户** | 好感 warmth / 耐心 patience | 对这个人什么态度 |

态度标签由两者组合算出，运行时不再二次判断。

## 会衰减，不会永久记仇

每个维度按半衰期回到基线：

| 维度 | 半衰期 |
|---|---|
| 心情 | 6 小时 |
| 精力 | 12 小时（深夜基线自动降到 0.3） |
| 耐心 | 1 小时 |
| 黏人 | 4 小时 |
| 好感 | 7 天 |

单次调节还有惯性上限（心情 ±0.15、好感 ±0.08），免得一句话就从生气变开心。

## 她怎么看待这件事

注入给模型的是**倾向**，不是数字：

```
【此刻的状态】
整体：有点闷
对这个人：闷着，想找人陪 —— 心情低，但对这个人有依赖：会想说话、会找他，只是嘴上不承认
不要说出这些，也别解释自己的情绪，用语气、话的长短和态度表现
```

注入走 `TextPart(...).mark_as_temp()` 追加临时内容块，**不修改 `system_prompt`**，不会击穿前缀缓存。

## 让情绪真的出现在聊天里

光有数值不会体现在对话里。这一版加了四层：

**1. 意愿（willingness）**

把心情、耐心、好感折算成 0~1，直接给出这一轮该怎么说话：

| 意愿 | 行为提示 |
|---|---|
| < 0.35 | 只回一两个字，说完一句就停 |
| < 0.52 | 话比平时短，不追问 |
| < 0.70 | 正常回应，不用刻意热情 |
| ≥ 0.70 | 可以多说一点，甚至主动问一句 |

**2. 自动触发（不依赖模型）**

即使她一次工具都没调，情绪也会动：

| 触发 | 变化 |
|---|---|
| 被说「笨/烦/滚/讨厌…」 | 耐心 −0.10、心情 −0.05、好感 −0.04（5 分钟冷却） |
| 被夸「可爱/喜欢/厉害…」 | 心情 +0.07、好感 +0.04 |
| 90 秒内连发 5 条 | 耐心 −0.06 |
| 超过 6 小时没说话后再出现 | 心情 −0.04、黏人 +0.10 |

**3. 负向偏差**

坏事的推力 ×1.6，衰减速度 ÷1.5——记仇比记得住久。尖峰（`spike=true`）可以一次推 0.4，用于被拉黑、被说很重的话。

**4. 余温与后悔**

一次变化超过 0.10 时，接下来 3~4 轮注入里会出现「你还在想刚才的事」。耐心掉到 0.20 以下时，5 分钟后会自动补一点心情——她事后会有点过意不去。

## 关系深度 bond

`warmth` 是「此刻喜不喜欢你」，`bond` 是「你们积累了多少」——两个分开算。

| | warmth | bond |
|---|---|---|
| 增长 | 被夸、被认真对待 | 聊天量（每句 +0.02，上限由总句数决定） |
| 半衰期 | 7 天 | 60 天 |
| 作用 | 语气 | **允许什么** |

`bond ≥ 0.30` 可以说点日常私事；`bond ≥ 0.55` 是「特殊的人」：可以说心事，而且**她不会说出口**——
注入里写的是「你对他比对别人松，但这件事你不会说出口」，不是「你们关系很好」。

### 冷启动

新装的人不是从「陌生」开始的：每收到一条消息，`warmth` 和 `bond` 都向 `min(0.6, 句数/300)`、`min(0.8, 句数/250)` 缓慢靠近。
聊得越多越亲近，**不依赖任何其它插件**，别人下载也能自然长出关系。

## 工具

`emotion_shift(scope, dim, delta, reason)` —— 让她自己被触动时调一点：

- `scope=global`：`mood` / `energy` / `patience` / `cling`
- `scope=user`：对当前说话的人 `warmth` / `patience`

## 面板

插件管理 → 她自己的情绪 → 情绪

- 顶部大卡：心情环 + 精力 / 耐心 / 黏人 三条
- 对不同的人：好感条 + 当前态度标签 + 说过几次
- 最近的变化：时间线，谁让她变了什么
- 调试：手动调节与重置（只改状态，不发消息）

## 接口

| 路径 | 说明 |
|---|---|
| `GET /state` | 全局 + 用户 + 事件 |
| `POST /shift` | 手动调节 |
| `POST /reset` | 重置（`what=global` / `all`） |

## 数据

`data/plugin_data/astrbot_plugin_emotions/state.json`，几百字节，坏了删掉即可重建。

## 和别的插件怎么分工

| 插件 | 管什么 |
|---|---|
| 她自己的情绪（本插件） | 心情、精力、耐心、黏人、对每个人的好感 |
| livelystate | 身体状态（体力、口渴、身体档案） |
| affection / private_companion | 关系阶段、主动消息、用户档案 |

本插件不读别的插件的文件，也不接管主动消息——只影响**表达**。
